# Power BI — รอข้อมูลและหัวข้อ

ยังไม่มี PBIX หรือสูตร DAX เพราะยังไม่ทราบตัวแปรและคำถามวิเคราะห์

หลัง Pipeline สำเร็จ เปิด Power BI Desktop → Get data → Text/CSV → เลือก `powerbi/export/dataset.csv` เลือก encoding UTF-8 จากนั้นเข้า Transform Data และตรวจชนิดข้อมูลด้วยตัวเอง โดยเฉพาะรหัสที่มีเลขศูนย์นำหน้า วันที่ เขตเวลา และหน่วย

เมื่อกำหนดหัวข้อแล้ว จึงสร้าง fact/dimension, ความสัมพันธ์, measures และตัวกรอง ตรวจยอดกับ SQL แล้วบันทึก PBIX ในโฟลเดอร์นี้ หลังรัน Pipeline ใหม่กด Refresh ด้วยตนเอง หากย้ายเครื่องต้องเปลี่ยน data source path

CSV เป็นข้อมูลที่ยังคงชนิดข้อความจากต้นทาง ไม่ได้ sanitize สูตรสำหรับโปรแกรม spreadsheet; หากเปิดใน Excel ต้องนำเข้าเป็นข้อความสำหรับข้อมูลที่ไม่น่าเชื่อถือ
